a) Conceptual

b) Applied

Question 3 (Reordering Factors)

Background: By default, R will plot categorical variables in alphabetical order. We can use factors to reorder these categories by their frequency or by the values of another variable to make our plots easier to read.

a) Conceptual

What is the functional difference between fct_infreq() and fct_reorder()? Give a brief scenario of when you would choose one over the other.

b) Applied

Load the msleep dataset from {ggplot2}. Calculate the average sleep_total for each biological order using summarize() and the .by argument. Be sure to name the new column mean_sleep and drop any missing observations. Next, use mutate() and fct_reorder() to reorder the order factor based on the average sleep time. Finally, pipe this into ggplot() to create a horizontal bar chart (geom_col()) showing mean_sleep on the x-axis and order on the y-axis.

Question 6 (Calculating Time Spans)

Background: R provides several ways to calculate the time span between two dates. Choosing the right tool depends on whether you are tracking human calendar time or exact scientific time.

a) Conceptual

In {lubridate}, what is the fundamental difference between a “Period” (like days()) and a “Duration” (like ddays())? Briefly describe a situation where using one instead of the other would lead to an incorrect calculation.

b) Applied

Run the provided code to create the missions dataset, logging the launch and splashdown times of historical spaceflights. First, use mutate() and interval() to calculate the exact span of time between launch and splashdown for each mission, saving it to a new column called mission_length. Next, create another column called duration_days by dividing your mission_length interval by ddays(1) to see exactly how many 24-hour duration periods the mission lasted. Print the resulting dataset.

missions <- tibble(
  mission = c("Apollo 11", "Apollo 13", "Artemis 1"),
  launch = ymd_hms(c("1969-07-16 13:32:00", "1970-04-11 19:13:00", "2022-11-16 06:47:44")),
  splashdown = ymd_hms(c("1969-07-24 16:50:35", "1970-04-17 18:07:41", "2022-12-11 17:40:30"))
)
