Question 1 (Code Style)

Background: The tidyverse style guide provides recommendations for writing clean, readable, and predictable code.

  1. Conceptual: According to the style guide discussed in lecture, function arguments generally fall into two categories: “data” arguments and “detail” arguments. How should we treat the names of these arguments differently when writing a function call, and why does this improve readability?

  2. Applied: The code chunk below works, but it violates several style guidelines regarding spacing, line length, and object naming. Rewrite the code to follow the tidyverse style guide.

Question 2 (Chunk Options)

Background: Quarto uses “hash pipes” to control the behavior of code chunks in our rendered documents.

  1. Conceptual: Explain the difference between the echo: false and eval: false chunk options. Provide a realistic scenario for when you might use each one.

  2. Applied: Write a code chunk that creates a histogram of the carat variable in the diamonds dataset. Use chunk options to ensure that the code itself is hidden in the rendered document, but the plot is still displayed. Additionally, use chunk options to set the figure’s width to 7, height to 5, and provide a descriptive figure caption.

Question 3 (Table Anatomy)

Background: The gt package allows us to build professional display tables step-by-step.

  1. Conceptual: When initializing a table with the gt() function, what is the purpose of the groupname_col argument? How does utilizing this argument change the structural layout of the resulting table?

  2. Applied: Filter the mpg dataset to only include vehicles made by “honda”. Select the model, year, trans, fl, cty, and hwy columns. Use gt() to create a base table that groups the rows by year. Add a professional title and subtitle, and use cols_label() to rename the columns to be clear and readable for a general audience. Note that you can use ?mpg to learn more about the dataset.

Question 4 (Table Styling)

Background: Once the core structure of a table is set, we can format its values and style its appearance to highlight important information.

  1. Conceptual: What is the conceptual difference between a formatting function like fmt_number() and a styling function like tab_style() in the gt package?

  2. Applied: Build on your code from Question 3b. Add a spanner label called “Fuel Economy” that arches over your city and highway mileage columns. Then, use an alignment function to center the text in the fl, cty, and hwy columns.

Question 5 (Plot Labels)

Background: Good plots communicate their takeaways clearly to the audience using descriptive text.

  1. Conceptual: By default, ggplot2 uses dataset variable names for axis and legend titles. Provide two distinct reasons why relying on these default labels is often insufficient or inappropriate for a professional data graphic.

  2. Applied: Create a scatterplot of the penguins dataset showing Flipper Length (flipper_len) on the x-axis and Body Mass (body_mass) on the y-axis. Color the points by the penguin’s species. Add a comprehensive set of labels using labs() to provide a title, subtitle, caption, and professional titles for the x-axis, y-axis, and legend. (As an optional challenge, add a hash pipe to hide the warning about there being missing values.)

Question 6 (Plot Scales)

Background: Scales control exactly how data values are mapped to the visual properties of a plot, including the limits and breaks of axes.

  1. Conceptual: If you have a continuous numeric variable mapped to the x-axis, what specific aspects of the plot do the limits and breaks arguments inside scale_x_continuous() control?

  2. Applied: Start with the chunk you created in Question 5b. Add a scale function to adjust the x-axis so that it strictly starts at 170 and ends at 240, displaying breaks at every 10 units. Then, add a manual scale function to change the colors of the points. You must provide a custom color value for all three species (“Adelie”, “Chinstrap”, and “Gentoo”).
