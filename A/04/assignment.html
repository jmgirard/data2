Question 1 (Tidy Data)

Background: Consider the following table regarding two hit songs.

Field Song 1 Song 2
Track “Anti-Hero” “Flowers”
Artist Taylor Swift Miley Cyrus
Release_Year 2022 2023
Streams_Millions 120 95

  1. Identify the violation: Which specific principle of Tidy Data does this table violate? Briefly explain how.

  2. Propose a fix: Describe how you would restructure this data to make it tidy. What should the columns be? What should the rows be? (You do not need to write code for this, just describe the new structure).

Question 2 (Data Files)

For the remaining questions, ensure the file “chocolate.csv” is saved in your project’s folder.

  1. Reading Data: Use the appropriate tidyverse function to read the “chocolate.csv” file into R and save it as an object named chocolate. Then, use a command to preview the dataset “at a glance.”

  2. Writing Data: Imagine you want to send a backup copy of this data to a colleague. Use an R function to write the chocolate object you created in part (a) to a new file named “chocolate_YYYY-MM-DD.csv” where YYYY-MM-DD is the date in the year-month-day format, which is preferred for data storage.

Question 3 (Rows)

Note: For these questions, do not save over the original chocolate object. You can just print the result.

  1. Filtering: We want to find the highest-rated chocolates from France. Filter the chocolate dataset to retain only observations where the company_location is “France” AND the rating is greater than or equal to 4.0.

  2. Distinct values: We are interested in the variety of bean origins. Use distinct() to find all the unique values in the country_of_bean_origin column.

Question 4 (Columns)

Note: For these questions, do not save over the original chocolate object. You can just print the result.

  1. Select: Create a subset of the data that contains only the company_manufacturer, review_date, and rating columns.

  2. Mutate: The cocoa_percent column is currently stored as a decimal (e.g., 0.75). Use mutate() to overwrite this column by multiplying the existing values by 100 (so 0.75 becomes 75).

Question 5 (The Pipe)

Question 6 (Pipelines)

For these questions, construct a single pipeline (chaining multiple pipes) to achieve the goal.

  1. Finding the Best: Which companies in Canada produced highly-rated chocolate in 2021?
    1. Start with the chocolate data.
    2. Filter for observations where company_location is “Canada” AND review_date is 2021.
    3. Filter for rating greater than or equal to 3.75.
    4. Select only the company_manufacturer, specific_bean_origin_or_bar_name, and rating columns.
    5. Arrange the result by rating in descending order.
  2. Dark Chocolate Analysis: We want to explore the darkest chocolates in the dataset.
    1. Start with the chocolate data.
    2. Filter for observations where cocoa_percent is exactly 1.0 (100% cocoa).
    3. Select the company_manufacturer, company_location, and rating columns.
    4. Arrange the results alphabetically by company_location.
